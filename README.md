# Пары Губкина — напоминания в Telegram

Каждые 5 минут GitHub Actions заходит в личный кабинет [lk.gubkin.ru](https://lk.gubkin.ru),
забирает расписание на день и присылает в Telegram:

- **утром в 07:30** — сводку пар на день;
- **за 15 минут до пары** — напоминание (что, где, кто ведёт).

Работает на серверах GitHub — домашний компьютер не нужен.

## Секреты репозитория (Settings → Secrets and variables → Actions)

| Секрет | Что это |
|---|---|
| `LK_LOGIN` | Номер пропуска для lk.gubkin.ru |
| `LK_PASSWORD` | Пароль от личного кабинета |
| `TELEGRAM_BOT_TOKEN` | Токен бота, полученный у @BotFather |
| `TELEGRAM_CHAT_ID` | Chat_id чата, куда слать уведомления |

## Файлы

- `gubkin_notify.py` — вся логика (python, только стандартная библиотека).
- `sent_state.json` — какие уведомления уже отправлены сегодня (коммитится ботом).
- `.github/workflows/notify.yml` — расписание и шаги прогона.

## Ручной запуск

Вкладка **Actions** → **Пары Губкина — напоминания** → **Run workflow**:
- «Тестовое сообщение» — проверка доставки в Telegram;
- «Подробный лог» — печатает в лог названия предметов (обычно выключено,
  репозиторий публичный).

## Если что-то сломалось

- Логи: вкладка Actions, последний прогон.
- Смена пароля в ЛК → обновить секрет `LK_PASSWORD`.
- Бот молчит → проверить, что не нажат /stop… нет, стоп не блокирует боту;
  проверить токен и chat_id.
